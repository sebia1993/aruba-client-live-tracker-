# 오류별 점검 방법

| 표시/증상 | 의미와 다음 확인 |
|---|---|
| 등록 형식 오류 | IPv4/MAC을 한 줄에 하나씩 입력합니다. 포트·명령어를 넣지 않습니다. |
| 10대 한도 | 기존 대상을 중지·제거한 뒤 등록합니다. 이력은 SQLite에 남습니다. |
| 중복 대상/동일 MAC 대기 | 같은 단말의 IP/MAC이 함께 등록되었는지 확인합니다. 먼저 활성화된 대상을 유지하고 중복 항목을 정리합니다. |
| 여러 후보 | IP 재사용/중복 등록 여부와 MAC·담당 MD를 확인하여 선택합니다. |
| 다른 대상 상세가 보임 | 목록에서 해당 행을 선택합니다. 선택 전환과 수집 시작/중지는 별도입니다. |
| 실행 후 목록이 비어 있음 | 대상 목록은 저장하지 않습니다. 다시 등록하고 기존 세션은 이력에서 확인합니다. |
| 모드/설정을 바꿀 수 없음 | 전체 추적을 중지하고 진행 중 수집이 정리될 때까지 기다립니다. |
| MD 매핑 없음 | MM의 Current switch 값을 해당 MD의 매핑에 추가합니다. |
| SSH 연결 실패 | 관리 주소/포트/경로/계정을 확인합니다. 단말 연결 해제라는 뜻이 아닙니다. 실패 후 재시도 대기가 있습니다. |
| 서버 키 승인 대기 | 순서대로 표시되는 지문을 별도 확인 후 처리합니다. 불필요한 대상은 중지합니다. |
| 서버 키 변경 | 자동 연결을 차단합니다. 실제 교체/키 변경을 관리자에게 확인합니다. 신뢰 파일을 무작정 삭제하지 않습니다. |
| 명령 지원 안 함/출력 형식 확인 불가 | ArubaOS 버전·역할·CLI 권한·잘린 표를 확인합니다. 알 수 없는 출력을 미등록으로 보지 않습니다. |
| 이전 조회값 | 이번 수집 실패로 마지막 유효 값을 보존한 상태입니다. 마지막 유효 시각을 봅니다. |
| RSSI/전송률 확인 불가 | 값 또는 단위가 검증되지 않았으며 추정값을 채우지 않습니다. |
| 다중 조회/그래프 간격이 길어짐 | 전체 수집은 최대 2개씩 순환하며 완료+주기를 적용합니다. 느린 장비와 대상 수를 확인합니다. |
| 저장/내보내기 실패 | 로컬 디스크 공간·쓰기 권한·다른 프로그램의 파일 잠금을 확인합니다. |
| EXE 실행 안 됨 | Windows x64·ZIP 전체 해제·DLL 누락·보안 제품 차단을 확인합니다. |
| 재빌드 폴더 정리 실패 | 기존 EXE와 관련 프로세스를 종료한 후 다시 빌드합니다. |
| 글자/버튼 잘림 | 창을 확대하고 스크롤·Windows 배율을 확인합니다. |
| 이력 파일이 커짐 | 종료 후 보고서를 내보내고 DB를 별도 보관합니다. SQLite는 로컬에 누적됩니다. |

지원 요청은 버전·Windows 버전·비식별화한 재현 단계와 오류 분류부터 공유합니다. 실제 비밀번호·원문 인증 로그·내부 SSID·운영망 스크린샷을 공개하지 마십시오.
