# 오류별 점검 방법

| 표시/증상 | 의미와 다음 확인 |
|---|---|
| 입력 형식 오류 | IPv4 또는 지원되는 MAC 표기인지 확인합니다. 포트/명령어는 검색창에 입력하지 않습니다. |
| 여러 후보 | IP 재사용이나 중복 등록 가능성이 있습니다. MAC과 담당 MD를 확인해 선택합니다. |
| MD 매핑 없음 | MM의 Current switch를 해당 MD 설정의 매핑에 추가합니다. 임의 전체 MD 검색은 하지 않습니다. |
| SSH 연결 실패 | 관리 주소/포트/경로/계정을 확인합니다. 단말 연결 해제라는 뜻이 아닙니다. |
| 서버 키 변경 | 자동 연결을 차단합니다. 관리자에게 실제 장비 교체/키 변경 여부를 별도 경로로 확인합니다. 파일을 무작정 삭제하지 마십시오. |
| 명령 지원하지 않음 | ArubaOS 버전/장비 역할/CLI 권한 차이일 수 있습니다. 다른 항목 수집은 계속될 수 있습니다. |
| 출력 형식 확인 불가 | 표가 잘렸거나 알려진 형식과 다릅니다. 0건으로 해석하지 않습니다. 진단 화면에서 로컬 원문을 확인합니다. |
| 이전 조회값 | 이번 수집은 실패했습니다. 마지막 유효 시각과 장비 상태를 확인합니다. |
| RSSI/전송률 확인 불가 | 해당 명령이 값을 제공하지 않거나 단위를 확인할 수 없습니다. 추정값을 채우지 않습니다. |
| 그래프 간격이 길어짐 | 수집 시간+설정 주기로 다음 조회가 진행됩니다. 중복 조회는 쌓이지 않습니다. |
| EXE 실행이 안 됨 | ZIP 전체 압축 해제, Windows x64, DLL 누락, 보안 제품 차단 여부를 확인합니다. |
| 글자/버튼 잘림 | 창을 확대하고 스크롤을 사용합니다. 글꼴 크기와 Windows 배율을 확인합니다. |
| 이력 파일이 커짐 | SQLite 기록은 로컬 디스크에 누적됩니다. 추적 종료 후 필요한 보고서를 내보내고 파일을 별도 보관합니다. |

지원 요청에 실제 비밀번호, 원문 인증 로그, 내부 SSID, 운영망 스크린샷을 첨부하지 마십시오. 프로그램 버전, Windows 버전, 비식별화한 재현 단계와 오류 분류만 먼저 공유하십시오.
