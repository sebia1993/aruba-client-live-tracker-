# 초급 엔지니어 사용 설명서

## 무슨 문제를 확인하는 도구인가요?

최대 10대 단말의 담당 AP/MD, 접속 정책(Role), 신호 품질 변화를 함께 봅니다. 10~60초 간격 사이의 짧은 끊김이나 로밍은 놓칠 수 있습니다. PHY Rate는 실제 파일 전송 속도가 아닙니다.

## 단일 추적

IPv4 또는 MAC을 입력합니다. `aa:bb:cc:dd:ee:ff`, `aa-bb-cc-dd-ee-ff`, `aabb.ccdd.eeff`와 대소문자를 지원합니다. 여러 후보가 나오면 IP/MAC/담당 MD를 확인하여 선택합니다. 다른 검색값으로 시작하면 새 세션을 만듭니다.

## 다중 모니터링

추적 방식을 다중으로 전환하고 IPv4/MAC을 한 줄씩 등록합니다. 최대 10대이며 잘못된 줄과 중복 항목은 메시지를 확인하고 수정합니다. 목록에서 행을 선택하면 그 대상의 접속 정보·그래프·이벤트·진단을 봅니다. 선택만 바꾸어도 다른 대상의 수집은 계속됩니다.

선택한 대상에 개별 시작/중지/일시 정지/재개/새로고침을 적용하거나 전체 버튼으로 일괄 제어합니다. 중지는 진행 중 작업을 취소하고 세션을 끝냅니다. 일시 정지는 다음 자동 조회를 멈추며 재개로 이어갑니다. 즉시 새로고침은 작업을 중복해서 쌓지 않습니다. 조회 주기는 공통 10/15/30/60초이고 완료 시점부터 계산합니다. 전체 수집을 최대 2개씩 순환하므로 대상과 장비 응답이 많으면 조회 간격이 길어질 수 있습니다.

동일 MAC으로 해석된 대상은 먼저 활성화된 항목을 우선하고 중복 항목을 대기시킵니다. 후보 선택이 필요한 항목이나 한 대상의 조회 오류는 다른 대상의 수집을 막지 않습니다. 서버 키 최초 승인은 순서대로 표시되며 각 장비의 지문을 별도 경로로 확인합니다. 변경된 키는 자동 승인하지 않습니다.

대상 제거 전에 중지하고 필요한 이력을 내보내십시오. 목록은 저장하지 않으며 프로그램 종료 후 다시 등록해야 합니다. 이미 수집한 이력은 SQLite에 남습니다. 데모/실장비·추적 방식·장비 설정은 전체 추적을 중지한 후 변경합니다.

## 화면 읽기

- **현재 접속 정보:** MM의 MAC·담당 MD와 MD의 AP/SSID/Role/VLAN입니다. 확인되지 않은 값은 `확인 불가`입니다.
- **이전 조회값:** 이번 수집이 실패하여 마지막 정상 값을 보존한 상태입니다. 마지막 조회와 마지막 유효 관측 시각을 비교하십시오.
- **SNR:** 신호와 잡음의 차이(dB)로 보통 높을수록 유리합니다. 마지막 수신 패킷 기준일 수 있으며 단독으로 장애 원인을 확정하지 못합니다.
- **RSSI:** 실제 dBm 필드가 확인될 때만 표시하며 ClientMatch 과거 값으로 대체하지 않습니다.
- **Tx/Rx PHY Rate:** 무선 링크의 물리 속도입니다. 실제 처리량이 아니며 방향은 CLI 출처를 확인합니다.
- **Role:** 인증 후 적용되는 접근 권한 정책으로 인증 변경과 함께 봅니다.
- **재전송률:** 같은 AP/MD의 호환되는 연속 카운터 차이로 계산합니다. 리셋·누락·로밍이면 연속 계산을 끊습니다.

연속 정상 관측의 AP/BSSID 변화를 로밍 관측으로 기록합니다. 표시 시각은 이동 시각이 아닌 감지 시각입니다. SSH 오류를 로밍/연결 해제로 바꾸지 않습니다. 이벤트의 관측 사실·추정 원인·권장 확인 항목을 구분하십시오.

## 이력과 내보내기

이력에서 세션과 기간을 선택해 대상별 CSV/HTML로 내보냅니다. 다중 모드의 통합 내보내기는 여러 대상의 세션을 함께 저장하고 대상·세션 식별자와 수집 시각을 구분합니다. 삭제·재등록 등으로 생긴 과거 세션은 이력에서 따로 확인합니다. 실패한 수집도 정상 값과 구분하여 남습니다.

HTML은 오프라인에서 볼 수 있으며 CSV는 수식으로 해석될 수 있는 문자열을 보호합니다. 보고서는 로컬 파일이지만 운영망 정보가 포함될 수 있으므로 접근 권한을 관리합니다.

## 데모 모드

가상 데이터 배너를 확인하십시오. 정상 접속·IP/SNR/전송률 변화·AP/Role 변경·재전송·해제/복구·MM/MD 오류·담당 MD 변경·출력 형식 오류·중복 후보를 재현합니다. `--multi-demo`는 10개 독립 가상 대상을 준비합니다. 실제 Aruba 출력이나 실장비 성능 검증은 아닙니다.
