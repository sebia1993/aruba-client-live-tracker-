# 초급 엔지니어 사용 설명서

## 무슨 문제를 확인하는 도구인가요?

특정 단말이 어느 AP와 MD에 등록되었는지, 접속 정책(Role)이 바뀌었는지, 신호 품질이 나빠졌는지를 시간 순서로 봅니다. 10~60초마다 조회하므로 그 사이 발생한 짧은 끊김이나 로밍은 놓칠 수 있습니다. 패킷 캡처와 동일하지 않습니다.

## 검색과 추적

하나의 검색창에 IPv4 또는 MAC을 입력합니다. `aa:bb:cc:dd:ee:ff`, `aa-bb-cc-dd-ee-ff`, `aabb.ccdd.eeff` 형식과 대소문자를 지원합니다. 결과가 여러 개면 IP/MAC/담당 MD를 확인하고 한 단말을 선택합니다. 자동으로 임의 단말을 고르지 않습니다. 다른 검색값으로 시작하면 새 추적 세션을 만듭니다.

시작은 주기 조회를 켭니다. 중지는 작업을 취소하고 세션을 끝냅니다. 일시 정지는 다음 자동 조회를 멈춥니다. 즉시 새로고침은 현재 작업이 끝난 후 다시 조회할 수 있게 하며 중복 작업을 쌓지 않습니다. 다음 예정 시각은 이전 수집 완료 시점과 설정한 주기로 계산하므로 느린 네트워크에서는 수집 간격이 길어집니다.

## 화면 읽기

- **현재 접속 정보:** MM에서 찾은 MAC과 담당 MD, MD가 보고한 AP/SSID/Role/VLAN 등을 표시합니다. `확인 불가`는 값이 제공되지 않거나 파싱을 확인하지 못한 것입니다.
- **이전 조회값:** 수집 오류가 나서 마지막 정상 값을 보존한 상태입니다. 단말이 현재도 연결되었다는 보증은 아닙니다. 마지막 조회와 마지막 유효 관측 시각을 함께 보십시오.
- **SNR:** 신호와 잡음의 차이(dB)입니다. 보통 높을수록 유리하지만 단일 수치만으로 장애 원인을 확정할 수 없습니다. CLI의 마지막 수신 패킷 기준일 수 있습니다.
- **RSSI:** 실제 dBm 필드가 확인될 때만 표시합니다. ClientMatch 과거 신호값으로 대체하지 않습니다.
- **Tx/Rx PHY Rate:** 무선 링크의 물리 전송 속도입니다. 인터넷 속도 또는 실제 파일 전송량이 아닙니다. Tx/Rx 방향은 CLI 출처를 확인하십시오.
- **Role:** 인증 후 적용되는 접근 권한 정책입니다. Role 변화는 인증 변경과 함께 볼 필요가 있습니다.
- **재전송률:** 같은 AP/MD의 연속 정상 관측에서 호환되는 카운터 차이가 있을 때만 계산합니다. 카운터 리셋/수집 누락/로밍은 계산을 끊습니다.

## 로밍과 이벤트

연속 정상 관측의 AP/BSSID 변화를 로밍 관측으로 기록합니다. 실제 이동은 두 수집 시각 사이에 발생했으며 표시 시각은 감지 시각입니다. SSH 오류를 로밍/연결 해제로 바꾸지 않습니다. 연결 해제는 연속적으로 확인된 미등록 결과 등 충분한 근거가 필요합니다.

이벤트의 **관측 사실**, **추정 원인**, **권장 확인 항목**을 구분하십시오. 예를 들어 SNR 저하는 관측 사실이지만 간섭·거리·단말 절전은 추가 확인이 필요한 가능성입니다. 인증 실패 원인은 실제 인증 CLI 이력이 있는지 확인한 후 판단하십시오.

## 이력과 내보내기

이력에서 세션과 기간을 선택해 CSV 또는 HTML로 내보냅니다. 보고서는 로컬 파일로만 저장합니다. 실패한 수집도 기록되며 정상 값과 구분됩니다. HTML은 네트워크 접속 없이 볼 수 있습니다. CSV는 스프레드시트 수식으로 해석되지 않도록 위험한 문자열을 처리합니다.

## 데모 모드

가상 데이터 배너가 표시됩니다. 정상 접속, IP 변경, SNR/전송률 변화, AP/Role 변경, 재전송 증가, 연결 해제/복구, MM/MD 오류, MD 변경, 출력 형식 오류 및 중복 검색을 재현합니다. 이 데이터는 실제 Aruba 장비 출력이나 성능 검증이 아닙니다.
